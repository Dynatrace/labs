Version history

What changed in each release of the Dynatrace Labs page (earlier called "Developer Community" and then "Cookbook"). Solutions themselves are not versioned here — they are synced every hour from Dynatrace/community-examples.

Cookbook 0.3 Current

October 2026 · polish

Solution overlay

  • Opening a solution no longer shakes: the overlay only fades in, nothing slides. A leftover slide-in animation from the old side panel was the cause.
  • A quick second tap or click right after opening (a double tap) no longer closes the overlay or presses a button inside it. Double-tap zoom is switched off; pinch zoom still works.
  • On phones the overlay is sized to the visible screen, so the buttons at the bottom are no longer cut off by the browser toolbar.

Buttons

  • No more arrows (↗) in buttons that open another page, such as "View on GitHub" and "Report issue". These links still open in a new tab.
  • Buttons have no frames: no outline or ring on "Explore solutions", the theme and menu buttons, the secondary buttons, the ✕ and copy-link buttons, pause/play and the page numbers. They use soft fills instead. The keyboard focus outline stays.

Quality

  • New automated checks for the calm opening, the quick double click, the missing arrows and frames, the visible focus outline, and the overlay buttons on short phone screens.

Cookbook 0.2

October 2026 · solution overlay and phone fixes

Solutions

  • A solution opens as an overlay on top of the list: the page stays visible, dimmed, behind it and keeps its scroll position. Close with the ✕ button, Escape or a click on the dimmed area; Tab stays inside the overlay.
  • Solutions without a screenshot no longer show an image area or placeholder.
  • The "Fresh out of the kitchen" tiles show only a centered type icon, without the icon text.

Phones

  • The page name is visible in the header again ("Cookbook" on narrow phones, "Dynatrace Cookbook" when there is room).
  • The search box says "Search for ready-to-use solutions", which fits instead of being cut off.
  • iPhones no longer zoom into the page when you use the search box or the filters: form fields use 16px text. Pinch zoom stays possible.
  • Clearing the search with the ✕ no longer opens the keyboard. Keyboard users keep their focus in the search box.

Quality

  • New automated checks for all of the above, and a check that the version badge and the newest release notes match.

Cookbook 0.1

October 2026 · new name and one-page design

The page is now called Dynatrace Cookbook and its version numbering starts again at 0.1. The releases below (0.1–0.4) are those of the page’s earlier name, “Developer Community”.

One page instead of two

  • The solution list with filters sits directly below the hero: no separate Explore page. Search filters the list as you type; the carousel gives way and the hero shrinks while you search.
  • Solutions open in the page instead of a side panel: Overview, Prerequisites, then Get started with the setup steps. Actions: View on GitHub, Report issue and, for apps, Request app.
  • "Fresh out of the kitchen" shows the 10 newest solutions as small icon cards, with pause/play next to the dots. "Most popular" and the category tiles are gone.

Filters and categories

  • Filters: Category, Technology, Type, all A–Z; the technology list has its own search field.
  • "Platform Governance" is now "Administration & Governance" and no longer picks up every template; solutions without a category land in "Other".
  • Prepared the type "CLI & Tooling" (appears once the repository has a cli-and-tooling/ folder).
  • 24 solutions per page, so rows are always full.

Usage analytics and accessibility fixes from 0.3 and 0.4 carry over unchanged.

Version 0.4

October 2026 · usage analytics

Analytics

  • Anonymous usage measurement with Dynatrace Real User Monitoring: page views, searches (including searches without results), filters, opened solutions and where they were opened from, downloads and other get-started actions, screenshot views, shared links and contribution clicks.
  • No names or e-mail addresses, no session replay; not active in automated tests or local previews.

Quality

  • Automated checks that every tracked action sends the right event.

Version 0.3

October 2026 · accessibility release

Keyboard

  • "Skip to main content" link on the first Tab.
  • Opening a solution moves focus into the panel; closing it returns to the card it was opened from.
  • Screenshots in the panel can be opened with the keyboard; closing the viewer returns to the screenshot.
  • On phones the filter panel takes focus, keeps Tab inside and gives focus back when it closes.
  • The maintainer table can be sorted with the keyboard.
  • Clear focus ring on the screenshot viewer buttons and the result cards.

Screen readers

  • The browser tab title says which page and which solution is open; a page change moves focus to the new page.
  • The number of results is announced when searching or filtering.
  • Result cards are real buttons; headings follow a correct order on every page and in the panel.
  • Sort order of the maintainer table is announced.

Visual and touch

  • Pause / Play button for the "Fresh out of the kitchen" carousel.
  • Readable link colour in dark mode; links in running text are underlined.
  • Darker orange for warnings in the maintainer view (it was hard to read on white).
  • Larger tap areas for the carousel dots and footer links.

Quality

  • Accessibility scan (WCAG 2.2 AA, all severities) on every page, the panel and the viewer, in light and dark mode, and at phone size.
  • New keyboard and screen-reader tests for all of the above.

Version 0.2

October 2026 · mobile release

Phones and small screens

  • Menu (☰) on phones with "AI & Agents", "Contribute" and the version history — they were hidden before.
  • The detail panel fits the screen: no sideways scrolling, long file names truncate, and the page behind the panel no longer scrolls.
  • The maintainer view no longer stretches the page on phones.
  • Shorter screenshot area, full-width main button and less empty space at the top.

Navigation

  • Cards on the home page open Explore without a filter, with the solution in the side panel.

Quality

  • New automated checks for phones: no sideways scrolling on any view, the panel fits and locks the page, the menu reaches every section.

Version 0.1

October 2026 · first versioned release

Content & automation

  • All solutions come from the Dynatrace/community-examples repository; nothing is curated by hand.
  • Hourly sync: new, changed and removed solutions appear on the page automatically.
  • Categories, technologies, files and the next step for each solution are derived from its README.
  • "Most popular" is ranked by unique visitors of each solution on GitHub.

Home

  • Hero with search suggestions and "Fresh out of the kitchen": the 8 newest solutions, 4 at a time.
  • Category cards for Agentic Operations, AI Observability and Developer, plus "And more".
  • Light and dark theme.

Explore

  • Search with relevance ranking, synonyms and typo tolerance; filters for technology, category and type.
  • "AI & Agents" view in the header.
  • Detail panel next to the results, with a shareable link for every solution and a full-page screenshot viewer.
  • "Get started": download the file (or all files as a .zip), copy Monaco/Terraform deploy commands, or request an app.

Quality

  • Automated tests for the catalog generator and the page, run on every pull request.
  • The catalog is validated before every sync is published.
